# CloudRobot — ターミナル顔の3Dモデル

顔に水色の「>_」を表示した、Room One用のテクスチャ付きFBXモデルです。

## 使い方

1. `git lfs pull` でモデルと画像を取得し、Unity 6000.4.9f1でこのプロジェクトを開きます。
2. インポート後、**Tools > Cloud Robot > Create Prefab** を実行します。
3. このフォルダ内にある `Prefabs/RoomOne_CloudRobot.prefab` を任意のSceneに配置します。

補助スクリプトは色テクスチャを割り当て、全高を1 Unity unit、原点を足元中央に設定します。マテリアルは `Materials/` に生成します。既存のSceneやPrefabは変更せず、再実行した場合は別名のファイルを生成します。

## 素材と制限

- `Models/CloudRobot_Terminal.fbx`：FBX 7.4形式で、501,340三角形、250,672頂点、UVと法線があります。
- `Models/*.fbm/`：4Kテクスチャが5枚あります。FBXの相対参照を保つため、書き出し時のファイル名やフォルダ名を維持しています。
- 補助スクリプトは色テクスチャを使用します。付属の法線・金属度・粗さのマップは自動設定されません。
- 静的モデルです。骨やリグ、歩行アニメーションの追加や、モバイル・大量配置向けの軽量化は行っていません。
- FBX構造、頂点と面の参照、UV、法線、画像の読み込みは検証済みです。Unity上でのインポート、描画、補助スクリプトのコンパイルは確認していません。
- Tripoの無料枠で生成した非商用利用向けの素材です。入手先と利用条件は [SOURCE.md](SOURCE.md) に記載しています。

制作元の画像やプロンプト、検証記録は `ArtSource/Features/RoomOne/CloudRobot/` にあります。
