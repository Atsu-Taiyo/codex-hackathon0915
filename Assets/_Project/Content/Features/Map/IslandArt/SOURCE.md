# Island artwork

PR #2 terrain is referenced from `Content/Common/TerrainKit` with its original source notes intact.

The faceted mesh, furnishings, vegetation, palette and animated water shader in this folder were authored for this project. `Editor/IslandArtBuilder.cs` and `Editor/WorldMapArtSetup.cs` are the reproducible sources. No external textures or third-party packages were added.

`Editor/RoomOneArtworkSetup.cs` renders the workshop kit and shared furnishings to `RoomOne_CloudWorkshop.png`. Character poses come from PR #3; see `RoomOne/CloudRobotSprites/SOURCE.md` for their provenance.
