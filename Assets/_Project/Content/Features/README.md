# Feature content
コードと同じ機能名で `<FeatureName>/<AssetName>/` を作り、その素材の Prefab・Textures・Materials・Models・Animations をまとめます。必要な種類だけ追加します。
例: `Player/Robot/Prefabs/Player_Robot.prefab` と `Player/Robot/Textures/Player_Robot_BaseColor.png`。
機能別シーンは `<FeatureName>/Scenes/`、音声は `<FeatureName>/Audio/` に配置します。
制作ルールはリポジトリの `docs/ASSET_WORKFLOW.md` を参照してください。
