# Terrain Kit

18 individual FBX meshes: 3 workshop structural parts, 12 outdoor terrain options and 3 background-only silhouettes.

Use **Tools > Terrain Kit > Create Individual Prefabs** to create color materials and static terrain colliders (Built-in/URP). Existing prefabs and materials are preserved on repeat runs. Unity compilation/rendering is not verified in the authoring environment.

See [usage, previews and validation](../../../../../docs/TERRAIN_KIT.md). Blender source: ArtSource/Common/TerrainKit/. No room or complete map is assembled by this kit.
